让桌宠陪你聊个人微信和企业微信：结合当前对话生成回复建议；按 **Tab** 或点击建议气泡填入，单击熊猫生成或重新生成。

## 功能

- **回复建议**：私聊自动推荐，群聊单击宠物生成，长回复可展开阅读。
- **企业微信私聊**：识别当前会话、来信方向与输入框状态；新版企业微信重启后会按进程身份自动重新连接。
- **自动跟随窗口**：个人微信与企业微信同时运行时，未手动固定实例的桌宠会跟随当前前台应用完成切换。
- **独立聊天窗口**：微信单独弹出的聊天窗口也会被识别并跟随；关闭独立窗口后会回到主窗口。
- **刷新后自动恢复**：聊天窗口切换布局或短暂无法读取时，稳定后会自动重连并继续生成。
- **私聊图片与视频**：个人微信和企业微信私聊图片都会读取当前可见内容交给支持视觉的模型；视频会识别为视频消息，并在能读取封面时把封面作为视觉参考，不会声称看过完整视频或听过声音。
- **两种填入方式**：按 **Tab** 或点击建议气泡，会把建议写入微信输入框，发送由你决定；已有草稿或正在中文输入时不会覆盖。
- **点击时自动聚焦**：点击建议气泡时会主动切回对应微信窗口并聚焦输入框，不再要求事先把微信放在前台。
- **单击重新生成**：无论个人微信还是企业微信，单击熊猫都会激活一条新回复；建议已存在、被取消或清掉时都可以再次生成。
- **跳过系统通知**：末尾是撤回、工作变更等系统提示时，会继续定位前一条对方消息作为回复目标。
- **未回复跟进**：最后一条是本人发出、对方还没有回信时，重新进入聊天或单击熊猫会生成一条自然跟进，不假装对方已经回复。
- **三种形象**：嗨嗨、DSH 鲸鱼、团团熊猫，可调整大小、开关动画。
- **好友与群聊记忆**：设置关系、回复偏好和表达示例，支持查看、修改、关闭和删除。
- **多种模型连接**：支持 ChatGPT 账号、DeepSeek 账号或 DeepSeek API。
- **托盘与灰字提示**：隐藏宠物后，可在微信输入框中查看回复建议。

## 开始使用

1. 下载并运行 Windows 安装包。
2. 在桌宠设置中打开“模型连接”，选择服务并完成连接。
3. 打开微信或企业微信私聊，保持输入框为空；私聊等待推荐，微信个人群聊可单击宠物生成。
4. 按 **Tab** 或点击建议气泡填入建议；单击熊猫可生成或重新生成，确认内容后自行发送。

更新前请从托盘退出桌宠。关闭宠物窗口会隐藏到托盘，可从托盘菜单退出。

## 使用环境与隐私

适用于 **Windows x64**。当前已验证个人微信 **4.2.0.13** 和企业微信 **5.0.13.6005** 的私聊文字消息与草稿填入，并支持两种应用的私聊图片；个人微信视频会尽量读取静态封面。新版微信优先使用系统界面识别，不再依赖固定内存地址；遇到界面结构变化时仍可能需要小幅适配。企业微信群聊及视频内容解析暂未启用，窗口最小化时暂停读取。

模型凭证、个人设置与好友记忆保存在当前 Windows 用户的本机目录，凭证和记忆使用系统加密。首次使用需自行连接模型；生成回复时，当前会话的相关内容会发送给你选择的模型服务。
